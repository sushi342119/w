# 工时记账 App

打工人记工时、记账的本地小工具。单 HTML 文件应用，无需联网、无需注册，数据保存在浏览器本地。

## 功能

### 日历页（首页）
- 月历视图，今天有蓝色高亮
- 已记工时的日期显示当日收入（金色徽章）
- 休息日显示"休"红色徽章
- 点击任意日期查看/编辑当日工时
- 左右滑动切换月份

### 工时页
- 按月汇总工作天数、总工时、总收入
- 完整工时明细列表，显示每天班次、工时、收入构成（工时收入+餐补+夜班补贴等）

### 添加记录（底部 + 按钮）
- 支出 / 收入 / 不计收支 三种类型
- 27 种支出分类 + 16 种收入分类（预置图标）
- 数字键盘快速输入金额
- 可填记录标题和备注

### 账本页
- 按月查看收支明细
- 左右箭头切换月份
- 每日收支汇总 + 明细列表
- 点击任意条目可编辑/删除

### 统计页（账本页右上角📊进入）
- 本周 / 本月 / 本年切换
- 总收入 / 总支出 / 结余
- 支出分类饼图 + 图例
- 分类明细排序

### 我的页
- **工资规则设置**：时薪、每日餐补、夜班额外补贴、加班倍率（按你图中"工时184元+餐补15元+夜班30元"的算法）
- 数据管理：导出 JSON 备份、导入数据、导出 CSV 表格、清空所有数据

## 使用方式

### 方式 1：本地服务器运行（推荐）
双击 `启动.bat`，会自动打开浏览器。

需要电脑装了 Python 或 Node.js 之一。

### 方式 2：直接双击 `index.html`
直接用浏览器打开即可使用，但 PWA 离线缓存功能会受限。

### 方式 3：手机访问（同一 WiFi）
1. 电脑运行 `启动.bat`
2. 查看电脑 IP（cmd 里 `ipconfig`）
3. 手机浏览器访问 `http://电脑IP:8888`
4. 浏览器菜单 → "添加到主屏幕"，从此像原生 App 一样用

## 工资计算

单日收入 = 工时 × 时薪 + 餐补 + 夜班补贴 + 加班费 + 其他补贴

默认时薪 23 元、餐补 15 元、夜班补贴 30 元（按你图中数据默认设置），可在「我的」页修改。

## 数据说明

- 所有数据存储在浏览器 localStorage
- 换浏览器、清浏览器数据会丢失记录
- **建议定期在「我的」页导出 JSON 备份**
